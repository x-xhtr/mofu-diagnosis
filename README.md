# MOFU診断 PWA — beta v0.8.0

MOFU診断は、相手との付き合い方を「良い・悪い」ではなく、4つのやさしい軸と16の景色として楽しむ診断です。

## 公開β版について

- 16問（M / O / F / U 各4問）
- 5段階回答
- 16タイプ判定
- PC / タブレット / スマホ対応
- 結果カード表示
- MOFUバランス表示
- シェア画像の生成・保存・共有
- Xシェア対応
- 「MOFUであそぶ」プロンプトページ
- 配布素材の利用ルールページ
- PWA対応

## プライバシー

回答内容はサーバーへ送信・収集・保存されません。診断計算とシェア画像生成はブラウザ内で行います。

アクセス解析、広告、外部API、回答データベースは使用していません。ページを再読み込み・閉じると、診断途中の回答内容は残りません。

## v0.8.0

- 質問を28問から16問へ整理（各軸4問）
- M軸を「始める・終える・共有する・話していない時間」の4方向から全面調整
- O / F / U軸も重複を減らして4問ずつへ整理
- F軸に「相手の好きなものが自分の好きにも増えるか」の質問を追加
- トップの所要時間を16問 / 約2〜3分へ更新
- 「MOFUであそぶ」ページを追加
- 16タイプの情景プロンプトを折りたたみ＋コピーボタンで配布
- もふマスコットのキャラクターデザインプロンプトと参考画像を追加
- 「MOFUであそぶときのお約束」ページを追加
- マスコット改変・個人二次創作・プロンプトアレンジOK、再配布・自作発言・商用利用NGを明記
