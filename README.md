# MOFU診断 PWA — beta v0.7.2

MOFU診断は、相手との付き合い方を「良い・悪い」ではなく、
4つのやさしい軸と16の景色として楽しむ診断です。

## 公開β版について

- 28問（M / O / F / U 各7問）
- 5段階回答
- 16タイプ判定
- PC / タブレット / スマホ対応
- 結果カード表示
- MOFUバランス表示
- シェア画像の生成・保存・共有
- PWA対応

## プライバシー

回答内容はサーバーへ送信・収集・保存されません。
診断計算とシェア画像生成はブラウザ内で行います。

アクセス解析、広告、外部API、回答データベースは使用していません。
外部リンクは制作者のX（@x_xhtr）のみです。

ページを再読み込み・閉じると、診断途中の回答内容は残りません。

## ローカル確認

このフォルダでターミナルを開き：

```bash
python -m http.server 8013
```

ブラウザで：

```text
http://localhost:8013
```

## GitHub Pages

1. このフォルダの中身をGitHubリポジトリへアップロード
2. Repository Settings → Pages
